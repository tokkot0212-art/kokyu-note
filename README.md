# 呼吸ノート

瞑想専用のシンプルなタイマーと記録アプリ（iPhone 12 mini 向け）。

- 時間をタップするだけで開始（終了時刻つき）
- すう・とまる・はくの秒数を設定
- 瞑想中は画面の大部分が「気づいた」ボタン
- 前後の気持ちを一言、場所・内容・時間・気づき回数を記録
- 設定：音量、アラーム音、回数、終了前の音、カウントダウン、リピート、インターバル、テーマカラー

記録はこの端末のブラウザ内に保存されます。機種変更前は「記録」タブの「記録をコピー」でバックアップしてください。

## iPhoneで使う
1. Safariで公開ページを開く
2. 共有ボタン →「ホーム画面に追加」
